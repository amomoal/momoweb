プライバシーポリシー

制定日：2026年8月23日

アプリ説明に戻る Topに戻る

「予定合わせ」（以下「本アプリ」）は、開発者（以下「当方」）が提供する、知り合い同士で予定を共有するためのアプリです。 本ポリシーは、本アプリの利用に際して取得する利用者情報の取扱いについて定めるものです。

1. 取得する情報

本アプリは、機能の提供にあたり以下の情報を取得します。

  • アカウント情報：メールアドレス、パスワード認証に必要な情報、GoogleまたはAppleアカウントによるログインの場合は各サービスから提供される識別情報
  • プロフィール情報：表示名、プロフィール画像
  • 予定・シフト情報：予定の日付、場所、内容、コメント、参加状況、リアクション
  • フレンド関係情報：フレンド申請・承認の状態、フレンドごとに公開するカテゴリの設定
  • カテゴリ情報：予定に付与するカテゴリ名・表示設定
  • 通知情報：フレンド申請・リアクション等に伴うアプリ内通知の内容
  • 端末・アプリ利用情報：アプリの不正利用防止のための検証情報（App Check）、Firebase等のインフラ上で生成されるログ情報

メールアドレスおよび認証情報の取扱いは、Firebase Authentication等の認証基盤を利用して行われます。

また、本アプリでは、広告の表示、アプリの品質向上、不具合の調査、パフォーマンスの改善等のため、Google Mobile Ads SDK、Firebase Crashlytics、Firebase Performance Monitoringその他の外部サービスを利用する場合があります。

これらのサービスにより、広告識別子その他のデバイス識別情報、広告の表示・操作に関する情報、クラッシュ情報、アプリの起動時間や通信性能等のパフォーマンス情報、端末・OS情報、IPアドレスその他の技術情報が取得される場合があります。

取得される情報は、本アプリの機能提供、安全管理、広告表示、障害解析およびサービス改善等の目的で利用されます。

2. 情報の利用目的

取得した情報は、以下の目的の範囲内で利用します。

  • 本アプリのアカウント認証、ログイン状態の維持
  • 予定・シフト情報の保存、フレンドへの共有および表示範囲の制御
  • フレンド申請・承認、公開カテゴリ設定に基づく予定の表示可否の判定
  • アプリ内通知の生成・表示
  • 不正利用・なりすましの防止
  • セキュリティの確保および本アプリの安定運用
  • 障害、不具合その他の問題の調査・対応
  • 利用者からのお問い合わせへの対応

3. 第三者提供・外部サービスの利用

本アプリは、Google LLCその他の事業者が提供する外部サービスを利用して、データの保存、認証、広告表示、障害解析、パフォーマンス測定その他本アプリの提供に必要な処理を行います。

主に以下のサービスを利用します。

  • Firebase Authentication
  • Cloud Firestore
  • Firebase Storage
  • Cloud Functions
  • Firebase App Check
  • Firebase Crashlytics
  • Firebase Performance Monitoring
  • Google Sign-In
  • Google Mobile Ads
  • Sign in with Apple

これらの外部サービスでは、各サービスの提供・維持・改善、広告表示、障害解析、不正利用防止その他の目的のため、端末情報、識別情報、ログ情報その他のデータが取得・処理される場合があります。

各サービスにおける情報の取扱いについては、それぞれのサービス提供者が定めるプライバシーポリシーその他の規定が適用されます。

上記の外部サービスを本アプリの提供に必要な範囲で利用する場合、または法令に基づく場合を除き、当方は利用者本人の同意なく個人情報を第三者へ提供しません。

4. フレンド間での情報共有について

本アプリは、「知り合い同士で予定を共有する」ことを目的としているため、表示名、プロフィール画像、公開設定の対象となったカテゴリに属する予定の日付・場所・内容、予定への参加状況・リアクション、予定の作成者名その他予定の作成者を示す表示は、フレンド関係および利用者が設定した公開範囲に応じて、他の利用者に表示される場合があります。

利用者は、本アプリが提供する設定の範囲内で、カテゴリ単位・フレンド単位等により予定の公開範囲を変更できます。 公開範囲を設定する際は、共有を希望しない情報が他の利用者に表示されないよう、ご自身の責任において設定内容をご確認ください。

5. データの保存期間・削除

利用者は、設定画面から「アカウント削除」を行うことにより、いつでも退会できます。 アカウント削除時には、当方が定める処理手順に従い、アカウント情報、プロフィール画像、フレンド関係、通知その他、当該利用者に紐づくデータを削除または必要に応じて匿名化します。

利用者が主催した予定については、他の参加者が保持する参加情報や予定データとの整合性を保つため、予定自体が残る場合があります。 この場合、削除された利用者を特定できる表示名、プロフィール情報その他の個人識別情報との紐付けを削除または匿名化し、退会した利用者を識別できない状態で保持するよう努めます。

通報機能により送信された通報記録その他、不正利用の防止、安全な運用または法令上必要な情報については、必要な範囲で退会後も匿名化または適切な方法で保持される場合があります。 また、システム上のバックアップ等にデータが一定期間残存する場合があります。

6. 利用者による情報の確認・修正・削除

利用者は、アプリ内の設定画面から、プロフィール情報、公開範囲設定、フレンド関係その他本アプリが提供する範囲内の情報について確認、修正または削除できます。 利用者本人から、当方が保有する本人の個人情報について、法令に基づく開示、訂正、利用停止、削除等の請求があった場合には、法令に従い適切に対応します。 アプリ内で対応できない事項については、本アプリに設ける問い合わせ方法をご利用ください。

7. 未成年者の利用について

未成年者その他法定代理人等の同意を必要とする方は、必要な同意を得たうえで本アプリをご利用ください。

8. セキュリティ

当方は、取得した情報を適切に管理し、不正アクセス、紛失、漏えい、改ざん等を防止するため、Firebaseのアクセス制御機能、App Checkその他の技術を用いた合理的な安全管理措置を講じます。 ただし、インターネットを通じた通信、クラウドサービス上での保存その他の情報処理について、完全な安全性を保証するものではありません。

9. プライバシーポリシーの変更

本ポリシーの内容は、法令の改正、本アプリの機能追加・変更、利用する外部サービスの変更その他必要に応じて変更することがあります。 変更後の内容は、本アプリ内または本ドキュメントへの掲載その他当方が適切と判断する方法により周知します。 利用者に重大な影響を与える変更を行う場合には、法令上必要な手続きを行うとともに、アプリ内での告知等、適切な方法による周知に努めます。
